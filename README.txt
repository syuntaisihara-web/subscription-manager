サブスク管理 Webアプリ Ver.0.1.0

【起動方法】
1. ZIPを展開します。
2. index.html をダブルクリックします。
3. Chrome / Edge / Safari などのブラウザで起動します。

【データ保存】
この初期版ではブラウザの localStorage に保存されます。
同じブラウザ・同じ端末であれば、画面を閉じてもデータは残ります。

【搭載機能】
・ダッシュボード
・サブスク登録 / 編集 / 削除
・契約中 / 解約予定 / 停止中
・毎週 / 毎月 / 毎年 / カスタム周期
・次回支払日管理
・支払済み登録と次回支払日の自動更新
・カレンダー
・支払履歴
・カテゴリー別分析
・支払方法別分析
・検索 / 絞り込み / 並び替え
・CSV出力
・JSONバックアップ / 復元
・ライト / ダークモード
・スマートフォン向けレスポンシブ表示

【今回あえて搭載していない機能】

・値上げによる年間影響額
・今後12か月の支払予測
